Symbol Compressor

Version: 3.0
Author: Rosendo Barde Hubilla Junior
Minimum NVDA Version: 2021.1

Overview

Symbol Compressor is an NVDA add-on that reduces the verbosity of repeated symbols and emojis in text. Instead of hearing "exclamation exclamation exclamation exclamation exclamation" for a string like "!!!!!", NVDA will simply say "5 exclamation". This makes reading text much faster and less annoying, especially on social media, chat apps, and web pages where people commonly use repeated punctuation or emojis.

Requirements

  • NVDA 2021.1 or later

Installation

  1. Download the symbolCompressor.nvda-addon file.
  2. Open the file with NVDA (press Enter on it, or go to NVDA Menu → Tools → Manage Add-ons → Install).
  3. Follow the prompts and restart NVDA when asked.

How It Works

The add-on monitors every piece of text that NVDA is about to speak. When it detects a sequence of the same symbol or emoji repeated consecutively, it replaces it with a spoken count. For example:

  • !!!!!! becomes → "6 exclamation"
  • --- becomes → "3 dash"
  • 😂😂😂😂 becomes → "4 face with tears of joy"

Compression only happens when the number of consecutive repetitions meets or exceeds the minimum count you configure. Below that threshold, the symbols are spoken normally.

Symbol compression also respects your NVDA punctuation level setting. If your punctuation level is set to None, symbols will not be compressed since NVDA would not speak them anyway.

Supported Symbols

The following punctuation and special characters are supported for compression:

. , ! ? ; : - _ = + * / < > @ # $ % ^ & ( ) [ ] { } | \ " ' ` ~

Emoji Support

The add-on fully supports modern emoji sequences including:

  • Standard emojis
  • Emojis with skin tone modifiers
  • Multi-part emojis joined with Zero-Width Joiner (e.g. family emojis)
  • Emojis with variation selectors

Emoji names are read from Unicode data, so NVDA will speak the official Unicode name of the emoji followed by the count.

Version 3.0 adds support for Emoji 18.0 (Unicode 18.0, September 2026) — 9 new emojis, 19 sequences with skin tones:

  • Cracking face
  • Leftwards thumb sign (+ 5 skin tones)
  • Rightwards thumb sign (+ 5 skin tones)
  • Monarch butterfly
  • Pickle
  • Lighthouse
  • Meteor
  • Eraser
  • Net with handle

Settings

You can configure Symbol Compressor by going to:

NVDA Menu → Preferences → Settings → Symbol Compressor

The following options are available:

Compress repeated symbols

A dropdown with the choices Off, 2, 3, 4 and 5. Choose Off to speak all symbols normally, or choose a number to compress repeated punctuation and special characters that repeat that many times or more. The default is 3. For example, with 3, the string "!!" (2 exclamations) is spoken normally, but "!!!" (3 exclamations) is compressed to "3 exclamation".

Compress repeated emojis

A dropdown with the choices Off, 2, 3, 4 and 5. Choose Off to speak emojis individually, or choose a number to compress repeated emojis that repeat that many times or more. The default is 3.

Uninstalling

  1. Go to NVDA Menu → Tools → Manage Add-ons.
  2. Find Symbol and Emoji Compressor in the list.
  3. Press Disable or Remove.
  4. Restart NVDA when prompted.
